# Sai, Capeta! — Android

Aplicativo Android de bloqueio de chamadas desconhecidas, em desenvolvimento.

Identidade visual aprovada: **celular sem chifres**, escudo dourado e capetinha vermelho assustado. Cores preto, vermelho e dourado.

## Como obter o APK de teste no GitHub (pelo celular)

1. Na página deste repositório, use **Add file → Upload files**.
2. Envie o arquivo **Sai-Capeta-projeto.zip** disponibilizado no ChatGPT, sem extrair o ZIP.
3. Confirme em **Commit changes**.
4. Abra a aba **Actions** → **Compilar Sai Capeta (ZIP)** e acompanhe a execução mais recente.
5. Se o workflow terminar com marca verde, abra a execução e baixe o artefato **Sai-Capeta-APK-teste**. Dentro dele estará o APK.

O APK gerado dessa maneira é um **APK debug** para testes. Ele **não é uma versão final para atualização permanente**. Para as próximas atualizações preservarem os dados, será necessário assinar versões release sempre com a mesma chave digital, mantida em segurança. Nunca envie essa chave ou senhas para um repositório público.

**Atenção:** as funções de bloqueio ainda precisam ser testadas em aparelho Android real. O filtro depende da autorização do Android e não cobre chamadas do WhatsApp nem todos os números ocultos.
