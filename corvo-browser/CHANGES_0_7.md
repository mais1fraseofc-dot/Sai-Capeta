# Corvo 0.7 Beta

- Tenta HTTPS com prefixo `www.` apenas quando o endereço sem prefixo falha por DNS ou conexão.
- Mantém autenticação biométrica, certificados TLS e bloqueador por site.
- Exibe diagnóstico se o domínio alternativo também não carregar.
- Compatibilidade para endereços conhecidos como `www.sambaporno.com`.
